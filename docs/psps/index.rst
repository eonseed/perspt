Perspt Specification Proposals (PSPs)
=====================================

Perspt Specification Proposals (PSPs) are the primary engineering governance and architectural decision records for the Perspt ecosystem. Each proposal captures the mathematical invariants, systems specification, rationale, and verification evidence for a significant change to the SRBN agent runtime, SDK, domain packages, or developer workflow.

**Read a record's state first:** a ``draft`` or ``discussion`` proposal is not an accepted or finalized contract until it reaches ``active`` or ``final``.
